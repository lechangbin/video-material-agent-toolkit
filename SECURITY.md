# Security policy

## Reporting

Report suspected vulnerabilities through GitHub's private security advisory
feature. Do not open a public issue containing credentials, Cookies, browser
profiles, private media URLs or reproducible account takeover data.

## Secrets

The project never requires API Keys or platform Cookies in source files, Skills,
command-line arguments or committed configuration. Semvideo reads its model key
from the configured environment variable. material-collector stores reusable
browser profiles only in the current Windows user's local application data.

## Platform and content safety

Use conservative request rates and comply with platform terms. Download access
does not establish copyright or other content rights. The project must not be
used to bypass access controls, evade account restrictions, collect private data,
or interfere with platform operation.
