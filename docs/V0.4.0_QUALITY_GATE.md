# v0.4.0 Top-K quality gate

Status: pending representative human-labeled data and approval. Passing the
synthetic unit tests and the Windows CPU smoke is not sufficient to publish.

Use complete structured candidate catalogs from real workflows, including
Chinese and English narration/theme segments. For each case, preserve the
frozen query plan, the full candidate artifact, the subagent Top-K, and the
embedding Top-K. A reviewer who has not seen the ranking marks each candidate
for theme relevance (0/1/2), each required visual facet (confirmed / uncertain /
absent), and whether a selected pair is a near-duplicate or overlapping shot.

Evaluate both routes at the same `max_k` on relevance (nDCG@K and precision@K),
confirmed facet coverage, and duplicate/overlap rate. Inspect every false
positive, false negative and language split. The current relative similarity
window and facet separation constants are provisional; approve or revise them
from these cases before marking Issues #4 and #5 done. Never interpret cosine
scores themselves as confirmed visual evidence.

Keep source media, credentials, and private browser profiles out of this
repository. The reviewed data may remain in a private workspace; publish only
aggregate metrics and non-sensitive failure descriptions in the Issue.
