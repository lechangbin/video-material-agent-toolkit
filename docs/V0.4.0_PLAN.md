# v0.4.0: configurable global Top-K

Authoritative scope: [Issue #2](https://github.com/lechangbin/video-material-agent-toolkit/issues/2).
Implementation order: [offline embedding route #4](https://github.com/lechangbin/video-material-agent-toolkit/issues/4), then [capability-gated routing #5](https://github.com/lechangbin/video-material-agent-toolkit/issues/5).

```text
workflow init (freeze mode)
  -> host capability report -> immutable route
  -> existing structured Semvideo candidate catalog
  -> subagent global Top-K OR local embedding global Top-K
  -> common selection result and complete audit
  -> parent Agent sufficiency / gap decision
```

The default is `auto`: prefer a text selection subagent, fall back to the
offline fixed model only when no eligible subagent can start. The workspace
default is `<workflow-root-parent>/selection-config.json`; a workflow override
is `--selection-mode`. `subagent_only` and `embedding_only` are explicit modes.
The model is not user-configurable in v0.4. The candidate set is cumulative
across rounds, and the embedding cache is keyed by candidate artifact hash and
model fingerprint. Do not put candidate summaries in the parent prompt.

Release gates:

- Windows x64 Python 3.14 packaged installation and offline model smoke;
- PowerShell syntax, four Skill contracts, both CLI test suites, Ruff and strict mypy;
- manually labeled Chinese/English relevance cases for Top-K quality;
- route-denial, invalid-result/no-switch, candidate lineage, audit and downstream
  gap-planning tests.

Full multimodal subagent control of understanding, annotation and summaries is
deferred to [v0.5.0 #3](https://github.com/lechangbin/video-material-agent-toolkit/issues/3).

The required evaluation procedure is in [V0.4.0_QUALITY_GATE.md](V0.4.0_QUALITY_GATE.md).
