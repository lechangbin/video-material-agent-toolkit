# 剪辑媒体规整

本上下文描述如何把已选源视频范围转换为技术参数一致、可可靠拼接的剪辑片段。它只负责确定性的媒体规整，不作内容选择、镜头排序或创意剪辑。

## Language

**源范围（Source Range）**:
对一个不可变源资产及其半开时间区间的引用，是规整处理的最小输入身份。
_Avoid_: 候选分段、正式片段、剪辑片段

**剪辑交付配置档（Editing Delivery Profile）**:
为一次剪辑工作冻结的视频、音频、时间基和容器技术约束；同一配置档的所有输出必须能够进入同一拼接集合。
_Avoid_: FFmpeg 参数、编码预设、处理策略

**规整片段（Conformed Clip）**:
从一个源范围按剪辑交付配置档确定性生成的派生媒体；它保留来源与时间范围追溯，但不替代或修改源资产。
_Avoid_: 原视频、工作区资产、素材片段

**拼接集合（Assembly Set）**:
共享同一剪辑交付配置档并已通过流结构、时间基和包级验证的一组规整片段；集合不表达最终排列、转场或叙事顺序。
_Avoid_: 成片、剪辑表、播放列表

**规整报告（Conformance Report）**:
记录输入事实、配置档、输出媒体事实、校验值及拼接兼容结论的版本化产物。
_Avoid_: FFmpeg 日志、检查报告、剪辑说明
