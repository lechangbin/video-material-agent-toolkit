# 短视频素材采集

本上下文描述从互联网发现可用内容，将其整理为可供后续 AI 短视频剪辑使用的素材片段。系统的价值边界止于素材进入素材库，具体剪辑过程属于下游能力。

## Language

**采集输入**：
人类为一次首次成片采集提供的只读脚本快照，最少包含完整视频文案及按主题意义划分的主题段；整体主题和内容建议可以省略并由 Agent 从文案推导。该输入是所有后续查询轮次不可漂移的语义依据。
_Avoid_：单一关键词、查询结果摘要、自动扩展主题

**主题段**：
在完整视频文案中按叙事主题和意义划分的连续内容单元，包含该段文案和主题内容，是一个查询计划的直接语境，但不规定镜头数量、顺序或构图。
_Avoid_：镜头段、分镜、场景段

**内容建议**：
人类可以随主题段提供的可选素材内容提示，用于帮助 Agent 提取视觉面向；缺失内容建议是正常输入，Agent 必须能够只根据文案工作。
_Avoid_：必填需求、分镜、检索表达

**查询计划**：
Agent 围绕采集输入中的一个主题段组织的素材发现意图，包含需要覆盖的视觉面向、多个检索表达、约束和搜索预算；一个主题段对应一个查询计划。
_Avoid_：查询句、关键词、分镜表

**采集平台范围**：
用户为一次采集工作声明的受支持平台非空子集；查询计划必须覆盖范围内每个平台，但允许各平台使用不同语言和检索表达，认证和搜索不能超出该范围。
_Avoid_：固定三平台、单一跨平台表达、隐式扩大平台

**平台检索分支**：
查询计划中面向一个范围内平台的检索表达、预算和发现策略集合；不同分支可以使用不同语言与表达，但共同追溯到同一主题段和查询计划。
_Avoid_：独立查询计划、平台范围、跨平台统一关键词

**平台网络类别**：
平台能力中冻结的网络边界；国内平台只允许默认直连，国外平台只允许经验证的本机代理，并在代理不可用时停止而不回退直连。
_Avoid_：运行时网络猜测、全局代理开关、浏览器通道

**检索表达**：
查询计划中可提交给某个平台的一条具体搜索表达；同一查询计划可以包含多条互补的检索表达。
_Avoid_：查询计划、主题段、镜头需求

**候选批次**：
一次搜索轮次在自动处理边界内冻结的候选内容集合；批次中的候选不经过语义初筛，统一进入下载与后续处理，超出自动处理边界的来源另行等待人工复核。
_Avoid_：精选结果、已接纳素材、最终素材

**候选内容**：
通过查询从外部平台发现、可能符合剪辑需要，但尚未被切分并接纳的原始内容。
_Avoid_：素材、最终素材、搜索结果

**人工复核来源**：
已被发现并记录，但因不满足自动处理边界而只向用户提供稳定来源信息的候选内容；只有人工批准后才进入下载和后续处理。
_Avoid_：处理失败、已下载素材、已拒绝来源

**媒体单元**：
候选内容中可独立下载、分析、切分和落库的最小原始媒体边界；一个候选内容可以包含多个媒体单元，例如 Bilibili 的一个 BV 来源下包含多个由 P/CID 标识的媒体单元。
_Avoid_：来源记录、素材片段、整个合集

**媒体显示几何**：
把编码宽高、旋转信息和像素宽高比规范化后得到的实际显示宽高比事实；它可以来自平台元数据预检或本地暂存媒体复核，并记录事实来源和可信阶段。
_Avoid_：仅编码分辨率、画布尺寸、文件扩展名

**比例资格评估**：
媒体单元针对目标显示比例的版本化判定；预检可以接受、拒绝或保持未知，本地暂存媒体的 FFprobe 复核才是进入工作区资产前的权威判定。
_Avoid_：下载失败、裁剪建议、后期画幅转换

**跨平台作品组**：
经本地内容指纹确认属于同一作品的多个平台候选内容集合；组内按平台优先级选择一个主来源进入切分落库，其他平台版本作为可回退来源保留。
_Avoid_：同名作者集合、相似标题集合、重复素材片段

**素材片段**：
从候选内容中切分出来、能够被下游 AI 剪辑独立选择和使用的视听内容单元。
_Avoid_：切片、搜索结果、原视频

**候选分段**：
视频理解模块从完整媒体中识别并返回的相关时间范围及其摘要等理解信息；它尚未经过采集 Agent 的 Top-K 选择，也不会因被返回而自动成为已落库的素材片段。
_Avoid_：素材片段、有效片段、原视频

**语义分段目录**：
视频理解模块针对一个完整媒体单元返回的全部可理解语义区间及其时间范围、摘要和语义信息集合；目录不能因主题相关性或分页限制静默省略有效区间。
_Avoid_：Top-K、已选素材、固定时长切片

**分段选择**：
采集 Agent 围绕一个查询计划，从本轮全部候选分段中选择相关、互补且覆盖必需视觉面向的全局 Top-K 集合；K 是成本上限而非必须凑满的数量，它不判断素材是否已经充分，也不安排最终镜头。
_Avoid_：视频理解、充分性判断、镜头编排

**有效片段快照**：
某个查询计划在特定版本下已成功提交并可供下游使用的素材片段累计视图，是判断素材是否充分的唯一事实来源。
_Avoid_：下载结果、候选数量、批次摘要

**素材缺口**：
下游主剪辑 Agent 对照采集输入和视频理解后的 Top-K 选择结果，判断仍未被候选素材
充分表达的视觉面向；它是下一轮 QueryPlan 的直接依据，但不能改变首版脚本定义的
主题。
_Avoid_：技术失败、搜索关键词、自动生成的新主题

**来源清单**：
一次采集任务的持久产物，记录所有已发现候选内容的稳定来源地址、平台标识和发现链路，不因其高质量媒体是否已下载或是否被自动剪辑采用而省略。
_Avoid_：临时播放地址列表、下载目录、有效片段快照

**采集会话**：
垂类 Agent 持续处理一次素材采集工作的上下文边界，拥有该工作产生的查询状态和来源清单，并引用素材工作区中的工作区资产，直到会话被归档或回收。
_Avoid_：单次请求、候选批次、查询轮次

**素材工作区**：
承载一组采集会话及其长期媒体资产的持久边界；会话可以在其中创建、归档或回收，但工作区资产只随素材工作区自身的生命周期和显式变更而变化。
_Avoid_：源码仓库、单个采集会话、临时下载目录

**工作区资产**：
由素材工作区持有、可被多个采集会话或剪辑项目引用的媒体文件；回收、归档或删除单个采集会话不会回收该物理资产。
_Avoid_：会话资产、素材片段、来源地址、一次性缓存

**标题素材视图**：
工作区资产面向人类和下游工具的可读路径视图；候选内容标题命名对应文件夹，媒体单元标题命名对应其中的视频文件，并以稳定来源标识消除重名。它引用同一份内容寻址工作区资产，不取代资产标识、完整性校验或去重边界。
_Avoid_：重命名内容寻址资产、下载暂存目录、来源清单

**低码率代理**：
为内容理解和后续修改取得的完整 720p 目标媒体副本；平台存在多个版本时选择最高且
不超过 720p 的版本，不把 1080p 或更高版本作为低码率代理。源视频最高分辨率低于
720p 时保留其最高可用版本。它属于工作区资产，不因单轮分析、会话回收或会话归档
而删除。
_Avoid_：素材片段、高质量源文件、一次性临时文件

**高质量媒体**：
下游剪辑实际选用素材后，按媒体单元从稳定来源重新取得的高码率媒体文件；它不作为采集阶段落库和充分性判断的前置条件。
_Avoid_：低码率代理、临时播放地址、有效片段快照

**视频理解模块**：
接收完整媒体文件，形成并返回该媒体单元的语义分段目录；它不按当前主题筛选 Top-K，也不判断整个查询计划的素材是否充分。
_Avoid_：分段选择器、充分性判断器、素材库

**视频理解/剪辑编排层**：
接收查找下载模块交付的低码率代理和来源清单，调用视频理解模块、隔离 Top-K
子代理，并由主剪辑 Agent 判断是否需要生成下一轮 QueryPlan；无需补搜时生成剪辑
表。它不把搜索或缺口判断塞进纯视频理解模块。
_Avoid_：查找下载 CLI、视频理解模块、素材库

**增量采集闭环**：
由查找下载模块执行每轮搜索和低码率代理下载，再由视频理解/剪辑编排层完成理解、
Top-K 和缺口判断，并在存在缺口时再次调用查找下载模块的跨模块过程。
_Avoid_：无限递归、一次性采集、全量爬取

**决策检查点**：
确定性采集流程已经提交当前状态，但必须等待指定 Agent 或人类提供版本化决策后才能继续的稳定暂停点；它不是会话失败或会话终态。
_Avoid_：技术失败、进度事件、交互式终端提问

**本机认证配置**：
由一个操作系统用户持有、可跨素材工作区复用的平台浏览器登录状态集合；采集会话只引用其稳定标识，不持有或归档其中的凭据。
_Avoid_：工作区登录态、会话 Cookie、素材资产

**本机浏览器通道**：
本机认证配置选用的品牌浏览器运行族；新会话可以按既定顺序选择可用通道，一旦选定便由会话冻结，后续认证探针、人工登录和平台访问不能跨通道回退。
_Avoid_：Agent 浏览器连接、可互换浏览器 Profile、浏览器插件会话

**平台访问显示模式**：
用户是否看见平台检索过程的执行选择；人工登录始终可见，检索默认在后台运行，用户可以显式要求显示。显式显示的窗口被关闭表示本次平台访问中断，不能静默转入后台。
_Avoid_：本机浏览器通道、登录模式、平台范围

**Agent 调用契约**：
Skill 向 Agent 承诺的自包含使用界面，覆盖定位确定性工具、构造有效请求、执行操作和解释结构化结果所需的全部信息；正常调用一次构造并规范化正式请求，只有版本或环境异常进入有界只读诊断。
_Avoid_：命令名称列表、运行时试探、源码探测

**素材库**：
保存已接纳素材片段，供后续 AI 剪辑检索和使用的持久化集合。
_Avoid_：搜索库、下载目录、数据库
