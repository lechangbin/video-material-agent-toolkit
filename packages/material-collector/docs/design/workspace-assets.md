# 素材工作区媒体资产

状态：已确认；具体目录和 CLI 定位参数待确认

## 逻辑所有权

- 完整低码率代理和已经按需下载的完整高质量媒体都属于素材工作区资产，不属于任一采集会话。
- 采集会话只记录对工作区资产的逻辑引用。
- 单轮视频理解、素材落库、一次剪辑完成、会话归档、会话回收或会话删除都不得自动删除这些媒体。
- 工作区资产随素材工作区整体搬移、归档和显式变更，使后续会话、修改和人工剪辑可以恢复使用。

## 物理文件身份

- 媒体文件使用内容哈希作为物理身份。
- 多个候选分段、查询计划、采集会话或剪辑项目可以引用同一物理文件，不为每个使用者复制文件。
- `collection-result.json` 保存逻辑资产身份、内容哈希、文件大小、本地或归档引用、媒体属性和生命周期状态。

## 清理

- 会话级生命周期操作只改变会话状态或会话引用，不进入物理资产清理流程。
- 自动流程不得仅因剪辑完成、会话暂停、会话回收或素材未被当前剪辑采用而删除文件。
- 物理资产只能由用户发起的素材工作区级显式操作改变；不得把“最后一个会话引用解除”直接等同于允许自动删除。
- 具体内容寻址存储、引用追踪和工作区级资产变更应通过可替换的资产存储接口接入。

## 剪辑交付物

- 媒体规整模块生成的规整片段是剪辑工作持有的可重建交付物，不是低码率代理或高质量源资产的替代品。
- 清理规整片段不得影响素材工作区资产；清理或归档素材工作区资产前，仍需遵守显式资产变更规则。
