# 人类输入与 Agent 职责

状态：已确认

## 人类输入

人类启动采集时最少提供一份版本化采集输入：

- 完整视频文案；
- 已按主题意义切分的主题段；
- 每个主题段的段落文案。

视频主题和每个主题段的内容建议都是可选字段。缺失时由 Agent 根据完整文案和主题段文案推导。人类不需要完成视觉策划、逐轮编写搜索词或逐轮判断素材缺口。

## 不可漂移锚点

- 首次提交的完整文案和主题段快照是该次首次成片采集的语义锚点，运行期间只读。
- 一个主题段对应一个查询计划。
- 后续递归轮次可以调整检索表达、实体、动作、场景词和平台表达，但不得改变该主题段在首版脚本中的主题意义。
- 查询结果标题、简介和已接纳片段只能帮助寻找新的表达方式，不能成为新的检索主题。
- 第一版不提供采集中途修改文案、调整主题段边界或局部失效查询计划的能力。
- 成品后的改稿与重新采集属于后续版本范围；未来实现时应创建新的采集输入版本，并可复用已有来源和工作区资产，但不得覆盖首次成片记录。

## Agent 负责

- 主 Agent 在开始首轮搜索前读取完整文案，一次性为全部主题段生成查询计划。
- 从完整脚本上下文和当前主题段中提取必需视觉面向；存在可选主题或内容建议时将其作为辅助输入。
- 生成首轮多平台检索表达。
- 下游主剪辑 Agent 使用视频理解和 Top-K 结果判断各视觉面向的实际覆盖，形成素材
  缺口及其证据。
- 下游主剪辑 Agent 在保持首版脚本语义锚点的前提下，针对素材缺口生成下一轮
  QueryPlan，再调用查找下载模块执行该轮。
- 达到充分性护栏、平台期或硬上限时，由剪辑编排层返回结构化终态。

## 规则服务负责

确定性规则不代替 Agent 的语义判断，而是验证和约束 Agent 结果：

- 检查每个必需视觉面向的独立有效片段数量。
- 检查累计有效时长和视觉表达类别。
- 检查 `max_rounds`、`max_videos` 和连续无新增覆盖轮次。
- 拒绝没有绑定原主题段或素材缺口的递归检索表达。

主剪辑 Agent 判断“缺什么”；规则服务验证“是否满足已确认的最低标准以及是否允许继续”。

## Skill 边界

Agent 使用一个总编排 Skill
`search-understand-refine-video-materials` 连接三个可复用的能力边界：

1. `collect-video-materials`：确定性启动、监控和恢复每轮 Collector 会话；
2. `semvideo`：通过公开 CLI 生成完整语义分段目录；
3. `select-video-segments`：由隔离子代理从完整目录选择 Top-K。

首轮视觉面向和检索表达由总编排 Skill 所在的主 Agent生成。Top-K 返回后，仍由
同一个主 Agent 对照只读脚本锚点判断缺口并生成下一轮检索表达，不再为这两个动作
创建独立的用户入口 Skill。总编排只通过版本化文件连接现有工具，不将理解或递归
推理放进 `material-collector` CLI 或 Semvideo。

完整文案、主题段和后续 Top-K 都已经存在于剪辑主会话，不为首轮规划或缺口判断
复制第二份子代理上下文。充分性护栏由规则服务实现，不作为可以自由改变阈值的
LLM Skill。

多个主题段的查询计划由主 Agent 一次性生成，随后按主题段顺序执行；全量分段选择仍按轮次交给隔离子代理。
