# Bilibili 来源与处理粒度

状态：已确认

## 决策

- 一个 BV 视频对应来源清单中的一个候选内容记录。
- BV 下每个由 `P/CID` 标识的分P对应一个媒体单元，可以独立下载、分析、切分和落库。
- 来源记录保存已发现分P的稳定标识、标题、顺序和规范页面地址。
- 搜索结果明确指向某个分P时，只将该媒体单元加入当前候选批次。
- 搜索结果没有指定分P时，默认只将第一P加入当前候选批次。
- 未进入当前批次的其他分P仍记录在来源清单中，处理状态为 `on_demand`。
- 只有检索明确命中、后续缺口补搜选中或人工选择时，其他分P才进入新的候选批次。

## 预算语义

`max_videos` 按进入自动下载队列的媒体单元计数。一个大型分P合集中的每个已接纳 `P/CID` 分别占用名额；超过 20 分钟的分P默认只进入人工复核，不因属于同一个 BV 来源而绕过自动处理门槛。

## 身份与幂等

- 来源身份键：`bilibili + bvid`。
- 媒体单元身份键：`bilibili + bvid + cid`；`page` 用于展示和顺序，不作为唯一稳定身份。
- 同一媒体单元被多个检索表达或轮次发现时合并发现链路，不重复下载或落库。
