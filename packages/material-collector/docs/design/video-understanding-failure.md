# 视频理解失败策略

状态：已确认

## 媒体单元级处理

每个媒体单元的视频理解任务独立执行和重试。一个媒体单元失败不撤销其他媒体单元已经完成的语义分段目录。

- `complete`：目录可以进入分段选择。
- `partial`：优先针对未处理范围续跑，默认不进入分段选择。
- `failed`：重试或处理预算耗尽，保留完整失败信息和恢复入口。

不得把 `partial` 或 `failed` 解释为内容不相关，也不得据此生成负关键词。

## 轮次结算

- 存在至少一个 `complete` 目录时，本轮可以使用完整目录继续分段选择、切分落库和充分性判断。
- 本轮最终充分时，可以带视频理解失败警告结束；失败媒体仍保留在来源清单和采集会话中。
- 没有任何 `complete` 目录时，本轮以 `understanding_failed` 结束，不得伪装成 `insufficient` 并启动盲目补搜。
- 失败媒体的完整低码率代理继续保留，可以由关联的补偿任务重新理解。

## 补偿

补偿任务复用原媒体单元身份、代理文件和理解幂等键，只处理未确认完成的范围。补偿成功后创建关联批次，重新执行分段选择、落库和充分性判断，不静默改写已经关闭的历史轮次。
