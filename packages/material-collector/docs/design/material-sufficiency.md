# 素材充分性判断

状态：已确认；数值允许按真实剪辑采用率校准

## 下游判断事实来源

下游主剪辑 Agent 只根据版本化文案、主题段输入和视频理解后的 Top-K 选择结果判断
语义覆盖及素材缺口。可选主题和内容建议可以辅助解释，但不得成为缺失时无法运行的
依赖。候选标题、简介、搜索数量和单纯下载成功都不能计入。

确定性规则服务不替代 Agent 对“是否表达了主题、缺少什么”的判断，只验证 Agent 给出的结构化覆盖关系是否满足数量、时长、多样性和停止上限。

## 第一版默认规则

主剪辑 Agent 没有识别出未覆盖的必需视觉面向，且同时满足下列规则护栏时，当前
主题段无需继续搜索：

- 每个必需视觉面向至少有 2 个相互独立的有效素材片段。
- 有效片段累计时长达到主题段旁白时长的 2 至 3 倍。
- 有效素材至少覆盖 2 类不同的视觉表达方式。

独立性不能仅按片段身份判断；同一时间范围、同一跨平台作品组的重复画面或实质相同表达不能重复计数。

同一物理素材片段可以分别服务多个主题段，并在各查询计划中独立判断相关性；但它在单个查询计划的同一充分性规则中只能计数一次。跨主题段最终是否重复采用属于下游剪辑决策。

## 继续搜索

Agent 识别到语义缺口或任一规则护栏未满足时返回结构化素材缺口，只针对缺失视觉面向生成下一轮检索表达。新查询必须绑定首版采集输入中的主题段，不得只沿来源标题盲目扩展。

只有语义不匹配可以改变查询语义。下载失败、时长超限、视频理解失败、落库失败、权利信息或技术质量问题只影响来源、恢复或人工复核策略，不生成负关键词。

## 停止条件

- 满足全部充分性条件时返回 `sufficient`。
- 连续 2 个已完成轮次没有增加任何缺失视觉面向的有效覆盖时，判定进入收益平台期。
- 达到 `max_rounds` 或累计 `max_videos` 后仍不充分时返回 `stopped_with_gaps`。
- 视频理解或落库发生系统性失败时返回对应技术失败状态，不伪装成素材不足。

## 校准

上述数值是第一版默认值。后续以真实剪辑采用率、人工补找率和被弃用原因校准，但每次任务必须把实际使用的规则版本和阈值写入查询计划结果，保证判断可解释、可重放。
