# 平台网络访问与代理策略

状态：已确认

## 默认直连

认证探针、浏览器搜索、详情解析、短链解析和媒体下载默认全部直连：

- HTTP 客户端不读取 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 或系统代理；
- Playwright Chrome 使用明确的直连参数；
- 本机 `10808` 或其他代理端口不会因环境变量或系统配置被自动使用；
- 第一版不提供平台采集代理配置。

后续若增加显式代理能力，必须是默认关闭、会话可审计的独立配置，不能静默继承
开发机环境。

## SSRF 防护

- 只允许 HTTPS。
- 稳定页面 URL 和临时媒体 URL 分别限制到已知平台与 CDN 域。
- 发起连接前解析全部 DNS 地址，任一结果属于回环、链路本地、私网、保留或未指定
  地址时拒绝请求。
- 不使用客户端自动重定向；每一跳解析 `Location` 后重新执行 scheme、允许域和 DNS
  校验，并限制最大跳数。
- 重定向后的最终响应仍必须来自对应平台允许的媒体 CDN。

这些规则同时适用于代理下载和按需高质量媒体下载。
