# 媒体下载与视频理解边界

状态：已确认

## 查找下载模块负责

- 发现并记录候选内容及媒体单元。
- 下载并保存每个自动接纳媒体单元的完整 720p 目标代理；平台存在多个版本时选择
  最高且不超过 720p 的版本，源视频低于 720p 时保留最高可用版本。超过 20 分钟的
  媒体单元只有经人工批准后才下载。
- 在下游 AI 或人工剪辑明确选用素材后，按媒体单元下载完整高质量媒体，并更新来源清单中的本地引用和下载状态。
- 将完整媒体文件、稳定来源身份和必要元数据交给外部视频理解模块；理解结果不绑定单个主题段，可以在同一会话内复用。
- 在 `integration_required` 检查点交付来源清单、低码率代理和跨平台作品组引用。

Top-K 入选和低码率素材落库不自动触发高质量媒体下载；高质量媒体只服务下游实际剪辑，不参与充分性判断。

## 查找下载模块不负责

- 不预先切割长视频。
- 不生成固定时长窗口或临时视频分段。
- 不决定镜头边界、片段边界或镜头编排。
- 不在自身内部实现视频语义理解。
- 不选择 Top-K，不判断剪辑素材缺口，不生成递归查询。

## 外部视频理解模块负责

- 读取查找下载模块交付的完整媒体文件。
- 自行决定长视频的读取、理解和分段策略。
- 返回全部可理解有效区间组成的语义分段目录，不按当前主题截断 Top-K。
- 为每个候选分段返回可定位的时间范围、摘要及后续判断所需的结构化理解信息。
- 显式报告目录是否完整、未处理范围和分页状态，不得静默截断。
- 不负责判断当前查询计划的素材是否已经充分。
- 不负责调用查找下载模块执行下一轮搜索。
- 具体字段和调用方式在获得接口文档后确定。

## 视频理解/剪辑编排层负责

- 调用视频理解模块并校验完整语义分段目录。
- 在隔离子代理中使用 `select-video-segments` Skill 选择 Top-K。
- 由主剪辑 Agent 判断素材缺口；需要补搜时生成下一轮 QueryPlan 并调用查找下载
  模块，不需要时生成剪辑表。
- 保证递归查询仍锚定首次文案和主题段，不把这一能力塞入纯视频理解模块。

## 落库边界

Top-K 候选分段的具体提交字段将在获得既有切分落库工具接口文档后确定。候选分段与已落库素材片段必须保持为不同状态，不能因视频理解模块或分段选择 Skill 已经返回结果就视为落库成功。只有切分落库工具确认实际提交并出现在最新有效片段快照中的片段，才能参与充分性判断。

## 文件生命周期

完整低码率代理属于素材工作区资产，外部视频理解模块完成单轮处理、会话归档或会话回收后仍然保留。超过 20 分钟且未经人工批准的来源没有本地代理，只保留来源清单记录。本模块不产生需要单独管理生命周期的切分缓存。
