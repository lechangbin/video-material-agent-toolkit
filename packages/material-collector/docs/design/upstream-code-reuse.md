## 复用范围

### MediaCrawler

可以选择性移植：

- Bilibili、抖音和小红书的平台请求客户端；
- 签名、页面字段解析和登录态检查逻辑；
- 与三个平台相关且确有必要的浏览器交互代码。

不得直接合入：

- 全局 `config`；
- `store` 持久化副作用；
- 应用级数据库、日志初始化和默认下载目录；
- 完整 crawler 生命周期和不属于第一阶段的平台；
- 与本项目 Python 3.14 依赖冲突且没有必要的分析、Web 或数据库依赖。

### Douyin_TikTok_Download_API

可以选择性移植：

- 分享文本、稳定 URL 和作品 ID 的解析；
- 抖音与 Bilibili 详情字段映射；
- 媒体下载及 Bilibili 音视频合并中经过审计的算法。

不得直接合入：

- FastAPI/PyWebIO 应用；
- YAML Cookie 持久化；
- Cookie 查询参数；
- 默认 `./download` 写入、直接终端打印和自带响应模型；
- TikTok 等第一阶段范围外能力。

## 接缝与适配

选择性移植的实现只能位于基础设施适配器内部，并分别满足：

- `SearchProvider`：检索表达与平台上下文进入，返回版本化规范候选批次；
- `SourceResolver`：稳定来源身份进入，返回媒体单元、时长和可下载能力；
- `MediaFetcher`：媒体单元与质量配置进入，返回经过校验的工作区资产结果。

每个接缝至少有实际平台适配器和离线测试适配器。调用方与测试只能通过这些接口观察行为，不能依赖上游全局变量、原始响应结构或文件布局。

## Python 运行时

- 正式实现保持 Python 3.14，不把两个上游仓库的官方锁文件合入本项目。
- 只引入被移植代码实际需要、已经在 Python 3.14 验证的最小依赖。
- Python 3.11 sidecar 只允许用于短期行为比对或兼容性实验，不作为正式架构依赖。

## 可用性门禁

每个平台适配器必须依次通过：

1. 离线字段归一化、错误分类和路径安全契约测试；
2. 不下载媒体的只读认证探针、关键词搜索和详情受控烟雾测试；
3. 小样本低码率代理下载、哈希和媒体探测测试；
4. 取消、登录失效、风控和平台接口变化的故障测试。

只有完成相应门禁后，适配器才能被标记为可用。源码中存在某项能力不能替代实际验证。

从参考项目移植的登录态检查必须适配为本项目的 `valid`、`invalid`、`challenge_required`、`probe_failed` 四态只读探针，不能直接暴露上游 Cookie、账号信息或原始响应。

核查依据见 `docs/research/reference-project-reuse-viability.md`。
