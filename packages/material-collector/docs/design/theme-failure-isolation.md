# 主题段故障隔离

状态：已确认

## 查询计划终态

每个主题段对应的查询计划独立进入终态，例如：

- `sufficient`
- `stopped_with_gaps`
- `understanding_failed`
- `selection_failed`
- `ingestion_failed`
- 其他明确的平台或一致性技术失败

一个查询计划的失败不撤销其他查询计划已经提交的来源、媒体资产、素材片段或充分性结论。

## 会话继续

- 当前主题段遇到预算内无法恢复的技术失败时，记录结构化问题并继续下一个主题段。
- 会话结束时汇总全部查询计划状态；存在失败或缺口但会话产物保持一致时，返回 `completed_with_issues`。
- 后续恢复可以只针对失败主题段及其未完成阶段，不重新执行整份文案。
- 共享来源和工作区资产仍可供后续主题段复用，即使首次发现它的查询计划最终失败。

## 整体停止

只有无法保证会话级一致性时才停止整个采集会话，例如来源清单无法可靠写入、会话状态损坏或资产身份冲突无法协调。单个平台、单个媒体、单个视频理解任务或单个查询计划失败都不是整体停止条件。
