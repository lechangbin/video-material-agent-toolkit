# 视频理解反馈与递归搜索由剪辑编排层负责

状态：accepted

查找下载模块负责首轮及后续显式 QueryPlan 的多平台搜索、稳定来源清单、媒体单元
解析、完整 720p 低码率代理下载和本地跨平台指纹确认。它不在没有外部接口的情况下
自行调用视频理解、选择 Top-K、判断素材缺口或生成递归查询。

下游视频理解/剪辑编排层接收低码率代理，调用纯视频理解模块生成完整语义分段目录，
再由隔离子代理选择 Top-K。主剪辑 Agent 根据这些结果判断是否存在素材缺口；需要
补搜时生成下一轮 QueryPlan 并再次调用查找下载模块，不需要时生成剪辑表。递归搜索
Skill 属于该剪辑编排层，而不是纯视频理解模块或当前采集执行 Skill。

该决策由仓库级 `search-understand-refine-video-materials` 总编排 Skill 落实。
Skill 通过版本化文件连接 Collector、Semvideo 与分段选择，不改变三个组件各自的
职责或持久状态。

高质量媒体继续是下游确定实际采用媒体单元后的按需能力，不属于本次边界调整。
