# 分类标签

工程技能使用五个标准分类角色。下表记录这些角色在本地 Markdown 任务追踪器中的实际状态字符串。

| 技能使用的角色 | 本地状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚未评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK Agent |
| `ready-for-human` | `ready-for-human` | 需要人类参与实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个分类角色时，使用表中对应的本地状态字符串。
