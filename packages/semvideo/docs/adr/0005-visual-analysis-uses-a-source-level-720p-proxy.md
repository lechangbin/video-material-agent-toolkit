# ADR 0005：视觉分析使用源级 720p 代理，导出坚持源视频

- 状态：Accepted
- 日期：2026-07-30

## 背景

实际素材库包含大量 4K 视频。候选场景检测、关键帧和镜头内连续帧会重复解码，
直接读取 4K 显著增加 CPU 时间；但正式片段和镜头导出必须保留源视频分辨率。
同一内容还可能创建多个处理任务，任务级代理会重复占用转码和存储成本。

## 决策

以源视频 ID 和版本化代理策略为缓存身份，在
`semvideo-data/sources/<source-video-id>/analysis/` 保存共享分析代理。

- 按旋转后的显示尺寸判断；宽超过 1280 或高超过 720 才创建代理。
- FFmpeg 保持宽高比、禁止放大、输出偶数尺寸的 H.264/yuv420p 视频轨，不复制
  音频、字幕或数据轨，保持源时间线和可变帧率语义。
- 候选场景检测、证据帧、九宫格和镜头语言分析使用代理。
- 内嵌字幕、ASR、批量正式渲染、片段导出和镜头导出始终使用受管源视频。
- 代理 sidecar 登记源哈希、策略和代理哈希；校验失败时在源级文件锁内原子重建。
- 转码同时占用 `media` 与共享 `ffmpeg_cpu` 预算。

## 结果

4K 视觉分析只需一次受控降码，多个任务可以复用；任务产物通过
`media/facts.json` 记录所用代理的相对路径、策略和哈希。代价是首次处理增加一次
转码和源目录存储，但代理可重建，不进入最终剪辑来源，也不改变源视频身份。
