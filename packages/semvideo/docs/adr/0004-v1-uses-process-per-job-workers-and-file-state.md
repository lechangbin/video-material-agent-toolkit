# V1 使用每任务独立 Worker 和文件状态，不运行常驻服务

V1 主要由本地 Agent 通过 CLI 使用，不提供前端、HTTP 服务或 SQLite 任务队列。CLI 创建自描述任务目录并启动无控制台窗口的独立 Worker；Worker 把状态、事件和阶段检查点原子写入文件，并通过分类文件锁限制 FFmpeg、ASR、LLM 和渲染并发。CLI 通过任务目录及 PID 创建时间查询、取消和恢复任务，不使用分布式租约或心跳。该方案牺牲系统重启后的自动恢复和远程访问，以减少单机 Agent 工具的常驻进程、认证、数据库迁移和调度复杂度；若未来出现持续人工操作、跨机器访问或无人值守跨重启恢复需求，再基于同一应用 Interface 和文件产物增加有状态 HTTP 服务。
