## 已接通的正式纵向切片

- Python 3.14.6 正式包、Typer CLI 和机器可读错误。
- 显式工作区初始化与向上发现；全部任务事实位于工作区 `semvideo-data/`。
- 源视频复制、工作区内内容寻址去重和每次使用前的哈希复核。
- 每任务独立 Windows 无窗口 Worker；关闭提交终端不影响执行。
- 原子状态、事件、PID+创建时间身份、attempt fencing、取消请求和阶段检查点。
- 媒体、ASR、LLM、渲染及共享 FFmpeg CPU 的跨进程文件锁。
- FFmpeg 8.1.2 原生探测、场景候选、`-fps_mode:v:0 vfr` 抽帧、dHash 去重。
- 内嵌字幕优先、faster-whisper 回退、时间戳转写和连续 3×3 九宫格。
- 九宫格取帧位置与正式候选切点解耦；正式候选时间线包含独立语义锚点。
- 单次完整上下文模型请求、一次结构/连续性修复，以及成功或失败 HTTP/网络尝试、
  原始响应和累计 token 的脱敏审计。
- 相邻边界的确定性合并；低置信结果保留为 `review`，不自动删除边界。
- 正式标题、长短摘要、视觉描述、实体、动作、关键词和完整片段转写。
- `retrieval/segments.jsonl`、分页列表、单条完整查询、HTML 检查报告。
- 默认惰性渲染；`process --render` 生成任务包内登记产物，`segment export`
  只向任务包外输出且不改变已完成任务包。
- 429 共享冷却、`Retry-After`、有界重试和 503/504 分类。
- 相同 idempotency key 的并发提交由工作区锁串行化，只创建一个任务。

正式代码位于 `src/semvideo/`，不导入 `semvideo_prototype` 或 `claude-real-video`。

- 并发锁、idempotency 并发提交和运行中 retry 无副作用。

- 本地假 OpenAI-compatible 模型服务下的真实后台 Worker、正式结果和 MP4 渲染。

- 稳定产物 Schema、未来版本拒绝、结构化进度、Doctor PyAV 能力，以及真实
  Worker 的取消和中断恢复。

`58.594s`。后续 `semantic-grid-v3` 已明确左闭右开区间及相邻片段共享同一边界
锚点的契约，避免因该格式歧义再次付费修复；该语法修正不改变本次三个片段的内容。
