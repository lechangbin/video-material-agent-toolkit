# 视频语义处理

该领域描述如何把一个源视频转换为可追溯的正式语义片段。它区分确定性的媒体事实、模型产生的语义判断和最终可交付产物。

## 输入与任务

**视频处理工作区（Semvideo Workspace）**:
一组相关源视频、处理任务和流水线产物共同归属的持久化边界；同一工作区可被不同 Agent 会话持续使用，不同工作区互相隔离。
_Avoid_: Agent 会话、处理任务、全局数据目录

**源视频（Source Video）**:
一次处理所引用的原始视频及其身份信息；相同内容应能通过稳定指纹识别。
_Avoid_: 原片、素材、输入文件

**分析代理视频（Analysis Proxy Video）**:
由源视频确定性生成、保持同一时间线并专用于视觉分析加速的低分辨率衍生物；它不替代源视频，也不能作为字幕、语音转写、剪辑或导出的来源。
_Avoid_: 源视频、正式片段、代理素材

**处理任务（Processing Job）**:
针对一个源视频和一个处理策略创建的、可观察且可恢复的一次处理实例。
_Avoid_: 运行、请求、分析

**任务准入（Job Admission）**:
应用层在工作区提交锁内，根据有效配置与当前非终态任务原子判断能否创建或重新启动处理任务；它限制 Worker 数量，不替代各处理阶段的资源锁。
_Avoid_: Skill 建议、媒体锁、模型并发

**处理尝试（Processing Attempt）**:
处理任务的一次实际执行；同一任务在中断或失败后可以产生新的处理尝试，但继续引用原任务和已经验证的阶段检查点。
_Avoid_: 新任务、Worker、重试次数

**处理策略（Processing Profile）**:
一组可版本化的处理意图与参数，例如目标内容类型、切分灵敏度、证据预算和模型选择。
_Avoid_: 配置、模式、预设

**模型提供商配置档（Model Provider Profile）**:
一组可选择的非秘密模型能力约束，固定提供商、模型、上下文预算、输出保留和同时在途请求上限。
_Avoid_: 模型、API 配置、处理策略

## 时间线与片段

**镜头（Shot）**:
由拍摄或剪辑形成的视觉连续单元；镜头变化是候选边界证据之一，但不等于叙事内容已经改变。
_Avoid_: 语义片段、正式片段、事件

**镜头语言标注（Cinematography Annotation）**:
对单个镜头的视点、景别以及随时间发生的运镜方向、速度和幅度变化所作的结构化描述；它描述拍摄方式，不解释叙事内容。
_Avoid_: 视觉摘要、镜头、正式片段、摄影风格

**叙事事件（Narrative Event）**:
围绕同一主体、目标、任务或动作阶段持续展开的内容单元；它可以跨越多个机位、景别和镜头。
_Avoid_: 镜头、主题标签、画面

**候选边界（Candidate Boundary）**:
确定性算法在源视频时间线上提出、允许语义片段开始或结束的时间锚点，包含来源、分数和时间戳；它不必与证据帧或九宫格格子的时间戳重合。
_Avoid_: 最终边界、关键帧、九宫格边界

**候选片段（Candidate Segment）**:
由相邻候选边界围成的最小连续时间范围；它是时间线规划单元，不要求被模型逐段独立理解。
_Avoid_: 镜头、正式片段、切片

**语义边界（Semantic Boundary）**:
两个相邻候选片段之间经语义判断后应保留的内容分界。
_Avoid_: 场景边界、镜头边界

**边界判断（Boundary Decision）**:
关于一个候选边界应保留、移除或交由人工复核的可追溯判断。
_Avoid_: 合并结果、相似度

**正式片段（Final Segment）**:
一个或多个相邻候选片段经边界判断后形成的连续、可解释视频范围。
_Avoid_: 候选片段、主题合集、镜头

**主题聚类（Topic Cluster）**:
对内容相似但不要求时间连续的正式片段建立的逻辑关联；它不改变源视频时间线。
_Avoid_: 合并片段、正式片段

## 证据与语义

**证据时间线（Evidence Timeline）**:
按源视频时间排序的证据帧、转写区间、OCR、镜头变化和候选边界集合；它只陈述可追溯事实，不预先作语义切分。
_Avoid_: 候选时间线、模型上下文、分段结果

**证据帧（Evidence Frame）**:
从源视频或其分析代理视频的某个确定时间点提取、用于支持语义判断的图像证据。
_Avoid_: 边界帧、缩略图

**时序九宫格（Temporal Contact Sheet）**:
把按时间排序的多张证据帧压缩到一张联系图中的视觉载体；每个格子是观察点，不是建议切分点。
_Avoid_: 分割九宫格、九个片段、边界图

**转写区间（Transcript Span）**:
在源视频时间线上带有起止时间的语音或字幕文本。
_Avoid_: 字幕、全文

**证据窗口（Evidence Window）**:
一次语义判断所读取的连续源视频范围，包含一个或多个时序九宫格、转写区间和候选边界；长视频中的相邻窗口允许重叠。
_Avoid_: 正式片段、模型请求、九宫格

**片段证据（Segment Evidence）**:
与一个候选片段关联的证据帧、转写区间、OCR 和确定性媒体特征的集合。
_Avoid_: 上下文、Prompt

**片段语义（Segment Meaning）**:
模型根据片段证据产生的结构化内容解释，包含事件、主题、参与者、动作和置信度。
_Avoid_: 摘要、标签、模型回复

**语义分段提案（Semantic Segmentation Proposal）**:
模型依据一个证据窗口提出的连续叙事事件范围及其候选边界引用；它必须经过跨窗口协调和确定性验证才能成为正式片段。
_Avoid_: 最终结果、合并计划、模型原文

**正式摘要（Final Summary）**:
针对一个正式片段生成、仅描述其实际包含内容的结构化摘要。
_Avoid_: 片段语义、全文总结

**检索片段记录（Retrieval Segment Record）**:
把一个正式片段的时间范围、结构化语义、转写信息、质量状态和可用产物引用汇总为下游检索可消费的稳定记录；它描述片段本身，不包含针对某次查询的相关性分数或排名。
_Avoid_: Top-K 结果、搜索索引、向量、正式摘要

## 计划与产物

**合并计划（Merge Plan）**:
由边界判断导出的、描述候选片段如何组成正式片段的不可执行数据。
_Avoid_: FFmpeg 命令、剪辑脚本

**流水线产物（Pipeline Artifact）**:
处理任务产生的、带类型、版本、校验值和来源关系的文件或结构化数据。
_Avoid_: 临时文件、输出

**阶段检查点（Stage Checkpoint）**:
证明某个处理阶段已经对指定输入成功完成并通过校验的不可变流水线产物；后续处理尝试可以据此跳过该阶段。
_Avoid_: 进度、任务状态、缓存文件

**模型运行（Model Run）**:
一次可审计的模型调用记录，包含提供商、模型、Prompt 版本、输入引用、输出、耗时和用量。
_Avoid_: 模型结果、调用日志
